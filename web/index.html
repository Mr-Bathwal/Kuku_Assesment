03 How it works

Taste is a model’s job. Arithmetic is not.

Where a clip starts and stops, how much dialogue is inside it, how many names a stranger has to track — all countable, instantly, for nothing, and impossible to get wrong. The model is spent only on the part counting cannot judge, and it is never handed a timestamp field it could fill in.

Standalone is the axis most tools skip, and the reason good scenes make bad promos. It counts speaking characters, phrases pointing off-screen, and series baggage — a character first met in episode 38 carries 37 episodes of history a cold viewer does not have. — named speakers across — scenes is a lot of history to arrive in the middle of.

05 The cut list

— promos, ranked. Pick one up and the desk opens on it.

—s to —s, across — different episodes, no episode used twice. The highlighted band is the promo window inside its episode; the ticks along the base are the beats, coloured by kind.

The desk is the actual tool: a keyboard queue where an editor approves, rejects, nudges an in-point by one beat boundary, and exports the decisions. Esc comes back here.

What this is. Problem 1 of the Kuku AI Generalist assignment: a tool that reads a microdrama screenplay and returns ranked 20–60s promo clips with exact cut points, a hook, a cliffhanger and a reason. Run with python -m cutlist run data/scripts. No pip install, no API key, no network. The write-up is docs/SOLUTION.pdf and the raw outputs are in out/.

Where it picks badly is in the write-up rather than hidden: it cannot see, so a silent held look scores near zero; spoilers are unguarded; the stitched promos are the weakest output; and against six episodes I hand-cut before running the tool on them it beats a trivial “last 40 seconds” baseline only narrowly, 0.380 against 0.349 mean IoU. Measuring that is what found three real bugs in the scorer.

Built with Claude (Claude Code), three research subagents, and my own reading of the screenplays for the gold labels. It was wrong in a way worth reporting: the first scoring function summed every signal axis for every beat, so a line screamed in terror scored 0.22, below a murmured question, because physical-shock terms only fire on action beats. It looked completely reasonable and was badly wrong.

No stock imagery and no fabricated stills. There is no video of this show, so there are no pictures of it here. The frames are the episodes’ own curves, the perforations are drawn from SMPTE ST 139 Table 1, and the leader keeps SMPTE RP 428-6 timing. The input pack is Kuku’s own content, shared for this assignment, so this page is not published anywhere.
